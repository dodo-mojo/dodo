# Security policy

## Supported versions

dodo is pre-alpha. Only the latest commit on `dev` gets security fixes.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/dodo-mojo/dodo/security/advisories/new). Do not open a public issue, PR or discussion.

Include the dodo commit, your platform, and the smallest request or code that reproduces the problem.

We aim to reply within 7 days and to agree on a disclosure date with you once a fix is ready.

## What counts

A crash, hang, memory error or unbounded resource use caused by network input is a vulnerability: dodo must never crash on input. Misuse of undocumented internals is not.

## AI-generated reports

A human must check that the issue is real before reporting it. Say which tools you used.
